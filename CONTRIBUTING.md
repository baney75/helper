# Contributing

Fix a dead official link in `src/data/programs.ts` and add a note in `research/SOURCES.md` with the date you checked it.

Keep screening copy free of the words eligible and ineligible. Allowed results are `likely_worth_applying`, `maybe`, and `probably_not`.

Do not add analytics, accounts, or a server that stores answers.

`npm test` and `npm run typecheck` should pass.
